# canoe-pyam-dashboard

Order of operation:

Convert the pyam excel workbooks in the output into csv and ensure units are added
Create a new virtual environment using the below script in the directory
python -m venv {your_chosen_name}
Activate the virtual environment
for windows
{your_chosen_name}\Scripts\activate
Install the required packages
pip install -r requirements.txt
Run the app
streamlit streamlit_app.py

This will open a browser window to look at the results. To close, use CTRL+C in the command line window.
